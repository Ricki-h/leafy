## 🚀 Descrição

O Leafy é uma rede social voltada para leitores, na qual é possível tanto avaliar e fazer resenha de livros quanto fazer postagens para amigos e seguidores sobre os livros que está lendo, leu ou quer ler.

> ⚠️ Projeto em construção

## 🔧 Funcionalidades

✔️ Cadastro e login de usuários, com autenticação de e-mail  
✔️ Perfil com nome, username e bio  
✔️ Editar dados do perfil e do usuário  
✔️ Seguir e ser seguido  
✔️ Buscar livros com filtros  
✔️ Cadastro automático de livros via APIs externas — Google Books API & Open Library  
✔️ Avaliação rápida de 1 a 5 leafs (estrelas)  
✔️ Resenha mais detalhada com pontuação em diferentes critérios  
✔️ Salvar livros em listas públicas ou privadas  
✔️ Remoção de resenhas e contas inadequadas

## 🖥️ Como rodar localmente

```bash
# Para o front
## Clone o repositório do front
git clone https://gitlab.com/Hugo505/leafy.git

## Acesse a pasta do projeto
cd leafy/app

## Instale as dependências
npm install

## Rode o frontend
npm run dev


# Para o back
## Clone o repositório do back
git clone https://gitlab.com/rick1n.htz/leapi.git

## Acesse a pasta do projeto
cd leapi

## Instale as dependências
npm install

## Rode o back (terminal diferente do frontend)
npm run dev
```

> Configure as variáveis de ambiente antes de rodar.
